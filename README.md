# TKtodo

极简待办清单。记录任务和精确到分钟的截止时间，完成打勾、逾期标红，可一键导入系统日历提醒。

单文件网页，零依赖，数据存在浏览器本地，断网也能用。

## 使用

打开 <https://tbk279.github.io/TKtodo/>，然后按平台安装：

- **iPad / iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 菜单 → 添加到主屏幕 / 安装应用
- **Windows / macOS**：Chrome 或 Edge 打开 → 地址栏右侧「安装」

装好后是全屏独立窗口，没有地址栏。

## 功能

**添加**

- 输入任务 + 截止时间，时间精确到分钟
- 时间用自建日历选择器：每一格数字下面直接显示星期几，可翻月、可一键跳到「今天」，时分用卷帘选择
- 标题留空也能添加，会自动命名为「新待办」

**列表**

- 按 DDL 从近到远排序，逾期未完成的置顶并标红
- 默认只显示**最近 5 条**（DDL 最近的），底部「展开全部 N 条」看其余，再点「收起」
- 时间气泡按紧急程度变色：距截止超过 1 天为灰、1 天内为蓝、剩余时间不足预估为黄、逾期连同日期一起变红

**预估时长**

- 预设「无 / 半小时 / 1 小时 / 2 小时」，或选「自定义」用 0–23 时、0–59 分两个卷帘精确设置，确认后卷帘收起
- 设了预估的任务，时间气泡旁边多一个「需 X」气泡，颜色与时间气泡一致
- 自定义拨到 0 小时 0 分时不生效，会提示

**编辑**

- 点任务就地展开面板，不跳转、不弹键盘
- 面板里标题默认只读，点「重命名」才变成输入框，改完「确认 / 取消」回到面板本身
- 时间、预估可直接在面板里改

**完成与删除**

- 点左侧圆圈标记完成，移入「已完成」
- 已完成任务标注 **如期 / 提前 / 逾期** 状态气泡：超过截止时间才完成标红「逾期」，提前 24 小时以上完成标绿「提前」，其余为灰「如期」
- 已完成标题右侧有「展开 ▾ / 收起 ▴」提示，点标题即可展开或收起
- 展开后默认只显示最近 5 条，底部「展开全部 N 条」看全部，再点「收起」回到 5 条
- 「多选已完成」和「清空已完成」都在已完成区顶部，不用滑到列表底部
- 删除的任务进入「最近删除」，默认保留 5 条，可设为 1–30 条
- 最近删除里的每一条都能「恢复」或「彻底删除」
- 删除待办、彻底删除、清空最近删除、清空已完成，都会先弹确认框并显示具体内容

**多选（待办 / 已完成 分开）**

- 两个入口：待办区的**多选待办**、已完成区顶部的**多选已完成**
- 进入后只在自己那一半生效：另一半的条目变暗、点不动，标题、展开按钮、清空按钮也都不响应
- 待办区只能**完成 / 删除**；已完成区只能**取消完成 / 删除**，不会出现用不上的按钮
- 底部操作条会写明当前范围（`多选待办` / `多选已完成`）和「已选 N 条」，`全选` 只选自己那一半
- 进入多选会自动展开那一半，保证「全选」看到的和选到的一致
- 按 Esc 或「退出」结束多选
- 批量删除同样先进「最近删除」，可恢复

**其他**

- 跟随系统自动深浅色
- 页脚显示当前版本号，有新版本时按钮亮红点、底部出现更新提示，可点「立即更新」或关掉

## 日历提醒

任务本身不发通知，提醒交给系统日历（可靠性更高：关掉浏览器、断网、重启都照常响）。

点底部「导入日历」打开弹窗：

- 勾选要导入的待办，支持**全选 / 全不选**
- 在同一个弹窗里设置提醒提前量：不提醒 / 提前 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天 / 2 天 / 3 天，或选「自定义」自己填数量 + 单位
- 确认后生成 `.ics` 文件

平台差异：

- **iOS / iPadOS**：直接唤起「添加到日历」
- **Android**：先下载 `.ics`，再点开它、选择用日历导入（Google 日历 App 不支持导入，需要系统日历或 Google 日历网页版）
- **Windows / macOS**：`.ics` 用系统日历或 Outlook 打开

## 备份与迁移

数据只存在当前设备的浏览器里，所以换设备、重装、清理浏览器数据之前，先导出一份。

点「最近删除」旁边的**备份**：

- **导出文件**：生成 `TKtodo-年月日-时分.json`，里面是全部待办、最近删除和提醒设置。手机上会先弹系统分享面板（可存进「文件」或发给自己），电脑上直接下载
- **导入文件**：选之前的 `.json`，会先显示里面有多少条待办、导出时间，再让你选
  - **合并导入**：保留现有数据，按 id 跳过重复的条目
  - **覆盖导入**：清空现有待办和最近删除，用文件内容替换，提醒提前量和保留条数也一起恢复
- 没有文件也能用：展开「没有文件？粘贴内容导入」，把 JSON 文本贴进去

## 注意

- 数据存在各自设备的浏览器里，**不跨设备同步**；清除浏览器数据会丢失，记得定期导出备份
- 导入是整份覆盖或合并，没有逐条挑选；覆盖导入无法撤销
- 日历里的事件是导入时的一次性快照，之后在网页里改了 DDL，日历那条不会自动更新
