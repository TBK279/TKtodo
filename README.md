# TKtodo

极简待办清单：记录任务和精确到分钟的 DDL，完成打勾、逾期标红。

一个 HTML 文件，零依赖，数据存在浏览器本地，不联网也能用。

## 使用

打开 <https://github.com> 上的 Pages 地址，然后按平台安装：

- **iPad / iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 菜单 → 添加到主屏幕 / 安装应用
- **Windows / macOS**：Chrome 或 Edge 打开 → 地址栏右侧「安装」

## 功能

- 输入任务 + 截止时间，按 DDL 从近到远排序
- 点左侧圆圈标记完成，点整行进入编辑
- 逾期未完成变红并置顶，显示「逾期 N 天」
- 跟随系统自动深浅色
- 数据存 `localStorage`，不上传任何服务器

## 注意

数据存在各自设备的浏览器里，**不跨设备同步**；清除浏览器数据会丢失。
