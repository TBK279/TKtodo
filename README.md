# TKtodo

极简待办清单：记录任务和精确到分钟的 DDL，完成打勾、逾期标红，可一键导入系统日历提醒。

一个 HTML 文件，零依赖，数据存在浏览器本地，不联网也能用。

## 使用

打开 <https://tbk279.github.io/TKtodo/>，然后按平台安装：

- **iPad / iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 菜单 → 添加到主屏幕 / 安装应用
- **Windows / macOS**：Chrome 或 Edge 打开 → 地址栏右侧「安装」

## 功能

- 输入任务 + 截止时间，按 DDL 从近到远排序
- 点左侧圆圈标记完成，点整行**就地展开**编辑框，保存 / 取消 / 删除都在原地
- 逾期未完成变红并置顶，显示「逾期 N 天」
- 已完成区可一键**清空已完成**
- 跟随系统自动深浅色
- 数据存 `localStorage`，不上传任何服务器

## 日历提醒

任务本身不发通知，提醒交给系统日历（可靠性更高：关掉浏览器、断网、重启都照常响）。

- 列表右侧的**时钟图标**：把这一条导入日历
- 底部**全部导入日历**：一次导入所有未完成任务（批量）
- **提醒**下拉：提前 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天 / 2 天 / 3 天 / 不提醒，或选「自定义」自己填数量 + 单位（分钟 / 小时 / 天）

平台差异：

- **iOS / iPadOS**：点时钟会直接唤起「添加到日历」
- **Android**：先下载 `.ics` 文件，再点开它、选择用日历导入（Google 日历 App 不支持导入，需要系统日历或 Google 日历网页版）
- **Windows / macOS**：`.ics` 用系统日历或 Outlook 打开

## 注意

数据存在各自设备的浏览器里，**不跨设备同步**；清除浏览器数据会丢失。
日历里的事件是导入时的一次性快照，之后在网页里改了 DDL，日历那条不会自动更新。
